# درمانیو — پروژه اندروید (APK)

برنامه کامل (سرور پایتون + دیتابیس SQLite) داخل خود APK قرار دارد و روی گوشی اجرا می‌شود؛
اطلاعات فقط روی همان گوشی ذخیره می‌شود. به Termux نیازی نیست.

## ساخت APK — راه ۱: بدون نصب چیزی روی کامپیوتر (GitHub)
1. در github.com یک ریپازیتوری خصوصی (Private) بسازید و کل محتوای همین پوشه را آپلود کنید.
2. تب Actions ← «Build APK» ← Run workflow.
3. بعد از چند دقیقه، از بخش Artifacts فایل `darmaniyo-apk` را دانلود کنید (داخلش `app-debug.apk` است).

## ساخت APK — راه ۲: Android Studio
1. Android Studio را نصب کنید و این پوشه را Open کنید (اجازه دهید Gradle Sync کامل شود).
2. Build ← Build Bundle(s)/APK(s) ← Build APK(s).
3. فایل در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## نصب روی گوشی
فایل APK را به گوشی منتقل کنید، «نصب از منابع ناشناس» را برای فایل‌منیجر یا Chrome فعال کنید و نصب کنید.
(این APK با کلید debug امضا شده؛ برای انتشار در استورها باید release امضاشده بسازید.)

## نکات
- بار اول اجرا چند ثانیه طول می‌کشد (راه‌اندازی پایتون و ساخت دیتابیس).
- کاربر پیش‌فرض: admin / admin123 — حتماً رمز را عوض کنید.
- این پروژه من (Claude) نوشته‌ام ولی هنوز ساخته و روی دستگاه تست نشده؛ اگر Gradle روی نسخه‌ای از
  Chaquopy یا یکی از پکیج‌ها خطا داد، متن خطا را بفرستید تا اصلاح شود.
- اندروید ممکن است برنامه را وقتی مدت طولانی در پس‌زمینه است ببندد؛ با باز کردن دوباره، سرور دوباره بالا می‌آید و اطلاعات حفظ است.
- از اطلاعات باید پشتیبان بگیرید (صفحه «پشتیبان‌گیری» برنامه)، چون با حذف برنامه دیتابیس پاک می‌شود.
